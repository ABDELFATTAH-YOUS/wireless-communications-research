# Wireless Communications Research

A structured research and learning repository focused on wireless communications, digital signal processing, communication systems, SDR, channel modeling, and related topics.

## Objectives

This repository documents the theoretical study, Python-based experiments, simulations, and practical implementations developed throughout the research process.

The main areas of study include:

- Signals and Systems
- Digital Signal Processing (DSP)
- Digital Communications
- Modulation and Demodulation
- Wireless Channel Modeling
- OFDM
- MIMO
- Software Defined Radio (SDR)
- Adaptive Communications
- Machine Learning for Communications

## Progress

### Day 1 — Signal Types

The first practical experiment focused on the fundamental representation and visualization of signals using Python.

Topics covered:

- Continuous-time signals
- Discrete-time signals
- Deterministic signals
- Random signals
- Periodic signals
- Sine waves
- Square waves
- Random noise
- Addition of noise to a sine wave

### Implementation

The Day 1 experiments were implemented using:

- Python
- NumPy
- Matplotlib
- Jupyter Notebook
